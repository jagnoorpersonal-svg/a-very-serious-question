Put your reaction stickers in this folder.

Expected file names (change them in CONFIG.rating.stickers in script.js):

  crying.png   rating 0–2
  sad.png      rating 3–4
  meh.png      rating 5–6
  happy.png    rating 7–8
  love.png     rating 9–10

Tips
- Transparent PNG or WebP, square, ~400×400px, under ~150 KB each.
- They get an automatic white "die-cut" outline, so cut-out images look best.
- If a file is missing, the site shows the emoji from the config instead, so nothing breaks.
